# Basic Owner UI Unit 3 Scope Lock

## In scope

- Verification of all existing owner UI states and dispositions.
- Focused regression tests for ordering, recovery, repeated submissions, and stopped-state persistence.
- Unit 3 planning, completion, and independent constitutional review records.
- Offline Windows verification only.

## Out of scope

- Parker server startup or connection.
- Ollama, Qwen, live-model, Unit3-C, or Ubuntu test execution.
- A real runtime adapter or changes to runtime composition.
- New availability/event contracts.
- UI redesign, dependency/version changes, Compose isolation changes, or application-main changes.
- Deployment, merge, push, commit, or release work.

## Change budget

No production-code change is authorized unless focused evidence reveals a genuine Unit 3 defect. The expected change set is tests and governance documentation only.
